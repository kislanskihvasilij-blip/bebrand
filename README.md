# BEBRAND · Краснодар и ЮФО

Лендинг Василия Кислянских — представителя федеральной сети BEBRAND в Краснодаре и Южном федеральном округе: регистрация товарных знаков, проверка названий, защита бренда.

Сайт свёрстан строго по «Руководству по использованию фирменного стиля Bebrand»: фирменные цвета (п. 1.6) и градиенты (п. 1.7), шрифты Roboto и Bitter (п. 1.9), асимметричная «галочка» (п. 1.10) и полигональный паттерн «огранка алмаза» (п. 1.12). Анимации повторяют язык движения [auros.global](https://www.auros.global/), но в цветах BEBRAND.

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # продакшен-сборка
npm run lint
```

Нужен Node.js 20.9+ (проект собран на Next.js 16.3, React 19.2, Tailwind CSS 4).

## Где что править

| Что | Где |
| --- | --- |
| Все тексты, цифры, контакты, FAQ | `content/site.ts` |
| Фото | `public/me/` |
| Фирменные ассеты (паттерн, мокапы) | `public/brand/` |
| Цвета, градиенты, кривые анимаций | `app/globals.css` (блок `@theme`) |
| Порядок секций | `app/page.tsx` |

Тексты лежат в одном файле, вёрстку для правок трогать не нужно.

## Структура

```
app/                    layout (шрифты, метаданные), page (секции + JSON-LD), globals.css (токены бренда)
components/ui/          shadcn-компоненты: scroll-expansion-hero, accordion, button
components/brand/       логотип и «галочка» — векторы, извлечённые из PDF гайда
components/motion/      анимации: подсветка текста при скролле, разъезжающиеся слова,
                        бегущая строка, «орбы», точечная сетка, sticky-медиа
components/providers/   плавный скролл Lenis + реестр блокировок скролла
components/sections/    секции страницы
content/site.ts         контент
lib/motion.ts           кривые и длительности анимаций
```

### Почему `components/ui`

Это путь shadcn по умолчанию (`components.json` → `aliases.ui`). CLI `npx shadcn add …` кладёт компоненты именно туда, а импорты вида `@/components/ui/...` одинаковы во всех shadcn-проектах. Поэтому сторонний компонент `scroll-expansion-hero` тоже лежит там.

### Что изменено в `scroll-expansion-hero`

API компонента сохранён. Доработки:

- `priority` → `preload`: в Next.js 16 `priority` устарел;
- фирменные цвета и шрифты вместо `text-blue-200`, острые углы вместо скруглений;
- управление с клавиатуры (↓, PageDown, пробел, End и обратно). В оригинале без мыши страницу было не прокрутить;
- сразу раскрыт при `prefers-reduced-motion`, переходе по якорю и восстановлении позиции прокрутки;
- обработчики подписываются один раз, а не на каждый шаг колеса; нормализуется `deltaMode` (Firefox);
- новые необязательные пропсы `mediaPosition`, `mediaOverlay`, `mediaAlt`, `onExpandedChange`;
- скрытый контент недоступен для Tab (`inert`), пока блок не раскрыт.

## Перед публикацией сверить с головным офисом BEBRAND

Цифры и условия взяты с biz-brand.ru (проверено 05.10.2026), но на разных страницах сайта они расходятся:

- цены «от 39 900 ₽», «от 46 000 ₽», «от 70 000 ₽» — действуют ли они для региона;
- формулировка гарантии «результат фиксируется в договоре»;
- цифры сети: 30 000+ клиентов, 25 000+ знаков, 50+ представительств;
- можно ли называть себя «официальным представителем» (сейчас на сайте просто «представитель»).

Instagram BEBRAND на сайт сознательно не выведен: в России Meta признана экстремистской организацией, и ссылки на её сервисы требуют специальной маркировки.
